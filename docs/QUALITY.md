  2. F1 клипа > F1 duration-only;
  3. p_perm(F1 клипа) ≤ 0.025;
  4. hit > max(random-time равномерное, random-time по допустимому диапазону);
  5. p_perm(hit) ≤ 0.025;

  8. p_perm(event F1) ≤ 0.025;
  9. p N1 ≤ 0.025 для обоих якорей;

## 3i. Этап 10 — exploratory weakly-supervised fit (pre-registered)

Статус: дизайн одобрен независимым ревьюером (critical-reviewer, claude-opus-5-5, 2026-10-18) как ONE предрегистрированный EXPLORATORY fit. Holdout закрыт. Продакшн fail-closed. Вес модели не поставляется (research-only).

**Типы supervision (ревьюер разделил их):**
- Позитивы экземпляров: 2 подтверждённых интервала под строгой маской (точечные кадры, фиксированный внутренний отступ на неопределённых сторонах).
- Негативные bags: 12 клипов с явным провайдерским «нарушений нет». Слабые, шумные, не подтверждены человеком; каждый кадр считается слабым негативом экземпляра.
- Исключено: 3 клипа с провайдерским позитивом и неизвестными событиями (positive bags). Их нельзя использовать как негативы; внеинтервальные кадры позитивных клипов тоже не негативы и не FP.

**Дизайн:**
- Признаки: замороженный SigLIP2, точечные признаки zone, центрированные по клипу; кэш фиксируется по sha.
- Единица: клип, n = 14. Кадры единицами не считаются. Дедупликация по хешу содержимого: одна побайтно идентичная пара негативов даёт 12 единиц и никогда не попадает в разные фолды.
- Модель: L2-логистическая регрессия с фиксированным заранее λ; равные веса клипов и балансировка классов; стандартизация только по обучающим клипам.
- Агрегация по клипу: K кадров, равномерно распределённых по клипу (фиксированное K), против смещения по длительности.
- Валидация: leave-pair-out (24 пары, одна модель на пару), не pooled LOCO (смешивает оценки 14 моделей).
- Базовые уровни: длительность (duration-only AUC на тех же 14 клипах, считается до lock; если 1.0, итог только описательный); always-positive (clip F1 0.25); позиционный приор; доля интервала (равномерная ссылка для локализации, f1·f2).
- Порог: правило фиксируется до просмотра оценок (например, максимум по обучающим негативным клипам).
- Метрики: LPO-AUC; clip F1 против always-positive; локализация на каждом held-out позитиве (argmax внутри интервала) против равномерной ссылки и позиционного приора; разрыв оценок внутри/вне интервала (описательно, внеинтервальные кадры неизвестны, не негативы); FP из 12 с доверительным интервалом (Clopper–Pearson).
- Исходы: `EXPLORATORY_TRANSFER_OBSERVED` / `NOT_OBSERVED`. Исход never GO.
- Ограничения запуска: один запуск, не более 5 минут, без подстройки после получения оценок; обучающий набор переиспользован 5+ раз; дизайн появился после этапа 7 (N1), поэтому запуск только exploratory.

**Ограничения интерпретации:**
- Scene identity: в каждом held-out фолде обучающие позитивы взяты из одного клипа, поэтому метка совпадает с идентичностью клипа. Clip-level AUC не отделяет действие от сцены, камеры или кассира. Только локализация внутри held-out позитива при зафиксированной сцене говорит о действии.
- Длительность: негативы длиннее; максимум по кадрам смещён, поэтому используется фиксированное K.
- Маленькая выборка: recall принимает значения 0/2, 1/2, 2/2. FP 0/12 имеет верхнюю 95 % границу 26 %. p-значения не сообщаются: обмениваемость нарушена сценой, длительностью и переиспользованием.

**Что «попадание» может значить:** на этом переиспользованном обучающем наборе направление, обученное на одном подтверждённом интервале против 12 провайдерских негативов, ранжирует интервал другого клипа выше (i) собственных прочих кадров этого клипа и/или (ii) негативных клипов.
